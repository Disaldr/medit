# medit — пакетная правка файлов

`medit` лежит в PATH (поставляется плагином). Когда нужно поправить несколько мест или файлов за один вызов, используй его через Bash, а не Python-скрипт:

```
medit [-n|--dry-run] [-C dir] <<'EOF'
=== path/to/file
<<<
старый текст (ровно 1 вхождение)
>>>
новый текст (пусто = удалить)
<<<*
старый текст (все вхождения, минимум 1)
>>>
новый текст
+++ path/to/new        (создать; +++! — перезаписать)
содержимое
EOF
```

- Маркеры — целые строки; блок кончается перед следующим маркером, его последний `\n` не входит в текст. Пустых строк-разделителей между блоками не ставь: они войдут в новый текст.
- Всё или ничего: при любой ошибке ни один файл не меняется (`exit 1`, сообщение `script:N: file: причина`, при промахе есть подсказка о совпадении без учёта отступов).
- Успех: `file: N ok (L12 L40)` — строки, куда легли замены.
- Замены в одном файле применяются по порядку; можно создать файл и тут же править его.
- Экранирования нет: текст, в котором есть строки-маркеры (`===`, `<<<`, `>>>`, `+++`), medit записать не может — для таких файлов используй Write/Edit.
- Если в правке встречается строка `EOF`, возьми другой ограничитель heredoc.
